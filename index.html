Scam Checker

A Java server reads a message and flags scam warning signs by fixed rules: pressure to act fast, gift card payments, fake delivery notices and lookalike links. A TypeScript page highlights each flagged phrase and explains why.

adult-income-fairness repo

Adult Income Prediction and Fairness Audit

A course team project that grew into a fairness audit. We cleaned 30,162 census records and compared three models, then I checked who the best model got wrong. Men were predicted above $50K about 26% of the time versus 9% for women.

gap -0.18 → -0.08 after reweighing · 0.6-pt accuracy cost
best model: gradient boosting, ROC-AUC 0.922

break-the-bot repo

Break the Bot

A chat-style web game with 10 levels. You try to get a local AI model to reveal a secret word, and each level adds a new defence. I wrote the server checks, including a filter that catches spaced-out and reversed spellings of the secret.

10 levels · runs on a local model
source on GitHub
Python Flask JavaScript Ollama
llm-audit repo

llm-audit

A test harness that runs each prompt 5 times against a local chatbot to measure private-data leaks and prompt-injection success. A control prompt separates the effect of an attack from normal behaviour. It compares a plain prompt against marker-based and "sandwich" defences, and a 1B model against a 3B model.

source on GitHub
Python Ollama llama3.2
